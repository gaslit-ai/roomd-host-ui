# Source catalog

> Verification date: 2026-04-25. This catalog backs the research pages in this directory. External protocol links cite the latest stable MCP pages available on that date. Local line links cite this checkout and the installed dependency versions in `node_modules`; re-check them after dependency upgrades, generated bundle changes, or large refactors.

No research note can be infallible. Treat normative words (`MUST`, `SHOULD`, `MAY`) as spec claims only when tied to a primary source below. Words like "recommended", "risk", "elegance", "acceptable", and "better" are subjective engineering judgments unless the sentence explicitly cites a normative source.

## External primary sources

- <a id="mcp-lifecycle"></a>**MCP-LIFECYCLE**: [MCP 2025-11-25 lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle), especially initialization, capability negotiation, and the operation rule that peers only use successfully negotiated capabilities.
- <a id="mcp-tools"></a>**MCP-TOOLS**: [MCP 2025-11-25 tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools), especially tool `inputSchema`, `outputSchema`, `structuredContent`, `isError`, annotations, and tool security considerations.
- <a id="mcp-tasks"></a>**MCP-TASKS**: [MCP 2025-11-25 tasks](https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/tasks), especially task capabilities, `tasks/list`, `tasks/result`, related-task metadata, progress, cancellation, and authorization-context scoping.
- <a id="mcp-sampling"></a>**MCP-SAMPLING**: [MCP 2025-11-25 sampling](https://modelcontextprotocol.io/specification/2025-11-25/client/sampling), especially `sampling: {}`, `sampling.tools`, and human-in-the-loop guidance.
- <a id="mcp-elicitation"></a>**MCP-ELICITATION**: [MCP 2025-11-25 elicitation](https://modelcontextprotocol.io/specification/2025-11-25/client/elicitation), especially form mode, URL mode, action semantics, and URL-mode security/state requirements.
- <a id="mcp-progress"></a>**MCP-PROGRESS**: [MCP 2025-11-25 progress](https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/progress), especially `_meta.progressToken` and task progress token lifetime.
- <a id="mcp-cancellation"></a>**MCP-CANCELLATION**: [MCP 2025-11-25 cancellation](https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/cancellation), especially base `notifications/cancelled` versus task cancellation.
- <a id="mcp-transports"></a>**MCP-TRANSPORTS**: [MCP 2025-11-25 transports](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports), especially Streamable HTTP `MCP-Session-Id` handling.
- <a id="mcp-apps-sep"></a>**MCP-APPS-SEP**: [SEP-1865: MCP Apps](https://modelcontextprotocol.io/seps/1865-mcp-apps-interactive-user-interfaces-for-mcp).
- <a id="mcp-apps-spec"></a>**MCP-APPS-SPEC**: [modelcontextprotocol/ext-apps draft `apps.mdx`](https://github.com/modelcontextprotocol/ext-apps/blob/main/specification/draft/apps.mdx), especially `ui://` resources, `_meta.ui.resourceUri`, visibility, AppBridge messages, and host/view lifecycle.
- <a id="assistant-ui-llms"></a>**ASSISTANT-UI-LLMS**: [assistant-ui `llms.txt`](https://www.assistant-ui.com/llms.txt), used as the official entry point for the current assistant-ui documentation surface.

## Installed package evidence

- <a id="pkg-versions"></a>**PKG-VERSIONS**: [`package.json` dependency versions](../../../package.json#L15) include `@modelcontextprotocol/sdk`, `@modelcontextprotocol/ext-apps` transitively, `@mcp-ui/client`, `@assistant-ui/react`, `@assistant-ui/react-ai-sdk`, `@ai-sdk/mcp`, and `ai`.
- <a id="sdk-elicitation-modes"></a>**SDK-ELICITATION-MODES**: [`@modelcontextprotocol/sdk` `getSupportedElicitationModes`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/client/index.js#L60) treats missing `form` and `url` fields under `elicitation: {}` as form-mode support for backward compatibility, while URL mode requires an explicit `url` field.
- <a id="sdk-capability-guards"></a>**SDK-CAPABILITY-GUARDS**: [`Client.assertCapabilityForMethod` / `assertRequestHandlerCapability` / task guards](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/client/index.js#L347) enforce negotiated capabilities in the installed SDK.
- <a id="sdk-capability-schemas"></a>**SDK-CAPABILITY-SCHEMAS**: [`ClientCapabilitiesSchema`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/types.d.ts#L572) includes client `sampling`, `elicitation`, `tasks.requests.sampling`, and `tasks.requests.elicitation`; [`ServerCapabilitiesSchema`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/types.d.ts#L776) includes server `tasks.requests.tools.call`.
- <a id="sdk-tool-schema"></a>**SDK-TOOL-SCHEMA**: [`ToolSchema`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/types.d.ts#L2381) makes `inputSchema` required and `outputSchema`, annotations, execution metadata, `_meta`, icons, and title optional.
- <a id="sdk-calltool-validation"></a>**SDK-CALLTOOL-VALIDATION**: [`Client.callTool`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/client/index.js#L490) rejects task-required tools on the plain path and validates `structuredContent` when an output validator is cached.
- <a id="sdk-task-stream-validation"></a>**SDK-TASK-STREAM-VALIDATION**: [`experimental.tasks.callToolStream`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/experimental/tasks/client.js#L59) adds task options for known task tools and validates final tool results against output-schema validators.
- <a id="sdk-private-validator"></a>**SDK-PRIVATE-VALIDATOR**: [`client/index.d.ts`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/client/index.d.ts#L529) declares tool metadata caches and `getToolOutputValidator` as private API.
- <a id="sdk-progress-request"></a>**SDK-PROGRESS-REQUEST**: [`shared/protocol.js`](../../../node_modules/@modelcontextprotocol/sdk/dist/esm/shared/protocol.js#L643) installs an `onprogress` handler and stamps `_meta.progressToken` when request options include `onprogress`.
- <a id="ext-apps-capability"></a>**EXT-APPS-CAPABILITY**: [`EXTENSION_ID`](../../../node_modules/@modelcontextprotocol/ext-apps/dist/src/server/index.d.ts#L310) is `io.modelcontextprotocol/ui`; [`McpUiClientCapabilities`](../../../node_modules/@modelcontextprotocol/ext-apps/dist/src/generated/schema.json#L52) carries `mimeTypes` on client capabilities.
- <a id="mcp-ui-client-capability"></a>**MCP-UI-CLIENT-CAPABILITY**: [`@mcp-ui/client` bundle](../../../node_modules/@mcp-ui/client/dist/index.mjs#L5593) exports the `io.modelcontextprotocol/ui` extension capability with accepted MIME types.
- <a id="ext-apps-bridge"></a>**EXT-APPS-BRIDGE**: [`AppBridge.oncalltool`](../../../node_modules/@modelcontextprotocol/ext-apps/dist/src/app-bridge.d.ts#L640), [`sendToolInput` / `sendToolInputPartial` / `sendToolResult` / `sendToolCancelled`](../../../node_modules/@modelcontextprotocol/ext-apps/dist/src/app-bridge.d.ts#L927), and [`connect`](../../../node_modules/@modelcontextprotocol/ext-apps/dist/src/app-bridge.d.ts#L1223) define the installed host/view bridge contract.
- <a id="ai-sdk-data-updates"></a>**AI-SDK-DATA-UPDATES**: [`ai/dist/index.js`](../../../node_modules/ai/dist/index.js#L5848) reconciles non-transient data UI message chunks by `type` and `id` before enqueueing state updates.
- <a id="assistant-ui-data-rendering"></a>**ASSISTANT-UI-DATA-RENDERING**: [`convertMessage.js`](../../../node_modules/@assistant-ui/react-ai-sdk/dist/ui/utils/convertMessage.js#L147) maps `data-*` parts to assistant-ui data parts and drops the AI SDK part `id`; [`MessagePartsGrouped.d.ts`](../../../node_modules/@assistant-ui/react/dist/primitives/message/MessagePartsGrouped.d.ts#L75) dispatches data parts by `name`, not by `id`.
- <a id="ai-sdk-mcp-modeling"></a>**AI-SDK-MCP-MODELING**: [`@ai-sdk/mcp` `mcpToModelOutput`](../../../node_modules/@ai-sdk/mcp/dist/index.mjs#L1605) converts MCP `content[]` blocks to AI SDK model output; [`tools()` construction](../../../node_modules/@ai-sdk/mcp/dist/index.mjs#L1936) preserves `_meta` and installs `toModelOutput`.
- <a id="ai-sdk-dynamic-tool"></a>**AI-SDK-DYNAMIC-TOOL**: [`dynamicTool` type](../../../node_modules/@ai-sdk/provider-utils/dist/index.d.ts#L1195) supports `toModelOutput` but not `onInputDelta`; provider tool factories expose input streaming callbacks separately at [`index.d.ts`](../../../node_modules/@ai-sdk/provider-utils/dist/index.d.ts#L1228).

## Repo evidence

- <a id="repo-chat-route"></a>**REPO-CHAT-ROUTE**: [`app/api/chat/route.ts`](../../../app/api/chat/route.ts#L40) has a module-scoped AI SDK MCP client/tool cache, a module-scoped SDK task client/registry, advertised task/elicitation/sampling capabilities, task wrappers, and app-only tool filtering.
- <a id="repo-browser-client"></a>**REPO-BROWSER-CLIENT**: [`components/providers/mcp-client-provider.tsx`](../../../components/providers/mcp-client-provider.tsx#L183) handles Streamable HTTP session pinning, CORS diagnostics, MCP Apps capabilities, task/elicitation/sampling capabilities, and list-changed callbacks.
- <a id="repo-host-app"></a>**REPO-HOST-APP**: [`components/mcp/host-app-renderer.tsx`](../../../components/mcp/host-app-renderer.tsx#L442) conditionally overrides `AppBridge.oncalltool` when `taskRegistry` is present; [`toolInputPartial` and cancellation forwarding](../../../components/mcp/host-app-renderer.tsx#L545) are gated by `viewInitialized`; final tool input/result are passed into `AppFrame` at [`host-app-renderer.tsx`](../../../components/mcp/host-app-renderer.tsx#L589).
- <a id="repo-dialog-handlers"></a>**REPO-DIALOG-HANDLERS**: [`components/mcp/tasks/request-dialog-handler.tsx`](../../../components/mcp/tasks/request-dialog-handler.tsx#L68) registers browser-side elicitation and sampling handlers.
- <a id="repo-task-context"></a>**REPO-TASK-CONTEXT**: [`components/mcp/tasks/context.tsx`](../../../components/mcp/tasks/context.tsx#L123) refreshes the task-support map from the provider's `toolUIs` name set, which can miss task-support-only or non-UI tool changes.
- <a id="repo-ai-adapter"></a>**REPO-AI-ADAPTER**: [`lib/mcp/tasks/ai-sdk-adapter.ts`](../../../lib/mcp/tasks/ai-sdk-adapter.ts#L108) wraps tools with `dynamicTool`, writes progress/terminal data parts, and returns raw `CallToolResult`.
- <a id="repo-sample-route"></a>**REPO-SAMPLE-ROUTE**: [`app/api/sample/route.ts`](../../../app/api/sample/route.ts#L51) calls `generateText` with model/system/messages/max tokens/temperature and does not pass sampling `tools` or `toolChoice`.
- <a id="repo-ui-surfaces"></a>**REPO-UI-SURFACES**: [`lib/message-parts.tsx`](../../../lib/message-parts.tsx#L25), [`TaskProgressPart`](../../../components/message-parts/task-progress-part.tsx#L43), [`TaskTray`](../../../components/mcp/tasks/task-tray.tsx#L36), and assistant-ui message rendering in [`thread.tsx`](../../../components/assistant-ui/thread.tsx#L236) are the current separate UI surfaces.

## Subjectivity register

These are design calls, not protocol facts: choosing a server proxy over two clients plus SSE, defaulting to one concurrency ceiling, using an 80% TTL warning, keeping terminal history size 128, labeling the AppBridge handler-replacement warning as acceptable, visual severity colors, and all "elegance", "complexity", "risk", and "future extensibility" ratings in the decision matrices.
